Contact & Technical Support

We welcome bug reports, feature suggestions, integration questions, and security feedback for Spaceship CLI. Below are the official contact and support channels available to developers, DevOps engineers, and autonomous agent integrators.

Primary Support Channels

  • GitHub Issues: For reporting reproducible bugs, command failures, and feature requests, open an issue at github.com/SpaceCorps/Spaceship-Cli/issues.
  • GitHub Discussions: For architectural questions, automation ideas, and agent tool use cases, join the discussion forum at github.com/SpaceCorps/Spaceship-Cli/discussions.
  • SpaceCorps Organization: Explore other high-performance developer tools and CLI ports maintained by SpaceCorps at github.com/SpaceCorps.

Security Vulnerability Reporting

If you discover a security issue or potential credential leak vulnerability in the keystore implementation, secret scrubbing, or CLI binary, please report it responsibly via GitHub Private Vulnerability Reporting on the repository security tab or contact the SpaceCorps maintainers directly.

Spaceship Platform Inquiries

For questions related to the underlying Spaceship domain registry, billing, DNS propagation, marketplace transactions, or account verification, please contact the Spaceship customer support team directly at spaceship.com.
